# Metrics

A diferencia del módulo de `tracking` que es el consumidor, `metrics` alberga las clases y estructuras que definen estrictamente fórmulas matemáticas y reglas de biometría.

- Contiene los algoritmos puros para el cálculo de ángulos (trigonometría para vectores de vista), cálculo de varianza y heurísticas específicas extraídas a partir de un arreglo estático de landmarks.
