# Security

Este módulo atiende cuestiones de seguridad y privacidad clínica, cruciales dado el entorno pediátrico y de la salud.

- Lógica para enmascaramiento y difuminado (blurring/anonymization) de los rostros en los videos guardados o exportados de la plataforma, usando algoritmos de OpenCV.
- Encriptación, sanitización y manejo seguro de los datos de pacientes si fuera necesario para una exportación confidencial.
